# Analyse of insurance claims data from kaggle datasources

Analyse of feautures and their influence on claim status that also influence risk rate in signing new contract with customer.
In dataset, there are categorical features , numeric ( descrete like 'subscription_length' and continuous 'torque' or 'bhp - brake horsepower' ), boolean like 'claim_status' or feautures in car like 'is_parking_sensors' etc.

#### Link to datasource : https://www.kaggle.com/datasets/litvinenko630/insurance-claims
